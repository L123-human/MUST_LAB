# 食堂好味道前端原型

直接打开 `index.html`，或在此目录运行 `python3 -m http.server 8765 --bind 127.0.0.1` 后访问 `http://127.0.0.1:8765/`。页面无需构建。

收藏入口在底部导航；默认提示登录。账户模块尚未接入，可主动选择“进入本地演示”试用收藏与反馈。数据仅保存在当前浏览器，共用设备可见。演示不代表安全登录或账户隔离已完成。

- 首页：最多五道推荐；“浏览全部匹配菜品”可访问完整匹配菜单。
- 菜品详情：独立收藏、点赞/不感兴趣、撤销、文字反馈；保留原有饮食记录。
- 收藏页：收藏列表及未收藏菜品的反馈；支持取消收藏和清除反馈。
- 测试：`node --test tests/personal.test.cjs`。
